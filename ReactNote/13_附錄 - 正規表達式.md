# 附錄 - 正規表達式

1. `^`：開頭符號
   `$`：結尾符號
   
   範例：
   
   `/^a/`：代表 a 開頭
   
   `/a$/`：代表 a 結尾
   
   `/^a$/`：代表 a 開頭 + a結尾 = 只能是 a
   
   `/a/`：沒有 開頭符號 也沒有 結尾符號，代表 字串只要有 a 就可以

2. 宣告方式有兩種寫法
   
   - 靜態：(效能較佳)
     
     使用「/」將正規表達式 夾起來
     
     ```tsx
     const re = /^a$/
     ```
   
   - 動態：
     
     透過 new RegExp() 進行封裝
     
     ```tsx
     const re = new RegExp("^a$")
     ```

3. 條件檢核
   
   透過 test() 這個方法，可以判斷 是否符合正規表達式的規則
   
   ```tsx
   正規表達式.test(要檢查的數值)
   ```
   
   - true = 符合；false = 不符合

4. 正規表達式的其他規則
   
   1. 驗證字元
      
      - `.*`：任意字串 
   
   2. 特定字元
      
      - `0-9`：接受數字0-9
      
      - `\d`：數字
      
      - `\D`：非數字
      
      - `\w`：數字字母與底線，等同 [A-Za-z0-9_]
      
      - `\W`：非數字字母與底線，等同 [^A-Za-z0-9_]
      
      - `\s`：空白字元
      
      - `\S`：非空白字元
   
   3. 次數
      
      - `*`：0次以上
      
      - `+`：1次以上
      
      - `?`：0次或1次
      
      - `{m}`：m次
      
      - `{n,}`：最少n次
      
      - `{m,n}`：m次到n次
      
      - `{m,n}?`：m次到n次之間最少次的
   
   4. 跳脫特殊字元
      
      `.`、`^`、`&`、`\`... 這類有特殊意義的符號
      如過要做為文字使用，必須在前面加上 `\`
      
      例如：
      
      - `\.` 為 `.` 這個文字
      
      - `\\` 為 `\` 這個文字
