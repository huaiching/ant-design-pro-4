# JS 介紹 - 空值判斷

JavaScript 的空值 有 `undefined` 和 `null` 兩種

- `null`: 空指標

- `undefined`: 未初始化

---

## 判斷是否為 undefined

```ts
const b = undefined
if (b === undefined) {
  console.log('b 是 undefined')
} else {
  console.log('b 非是 undefined')
}
```

---

## 判斷是否為 null

```ts
const a = null
if (a === null) {
  console.log('a 是 null')
} else {
  console.log('a 非是 null')
}
```
