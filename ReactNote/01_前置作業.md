# 前置作業

## 環境搭建

1. 安裝 Node.js (npm)
   
   https://nodejs.org/en/ 
   
   或是 前往 `工具` 資料夾，解壓縮 `node-v14.17.6-win-x64.zip`
   
   並設定環境變數
   
   1. 新增 變數
      變數名稱：NODEJS_HOME
      變數值：node 的 資料夾位置
   
   2. PATH 新增
      `%NODEJS_HOME%\`

2. 前往 node 資料夾，透過 CMD 依序執行下面指令
   
   ```textile
   npm config set always-auth true
   npm config set strict-ssl false
   npm install yarn –g
   yarn config set strict-ssl false
   arn config set ignore-engines true
   ```

3. 於 使用者資料夾 開啟 `.yarnrc` 新增下述內容
   
   進行 Proxy 設定
   
   ```textile
   https-proxy "http://OA帳號:OA密碼@hqwebgate4.mli.com.tw:8080"
   proxy "http://OA帳號:OA密碼@hqwebgate4.mli.com.tw:8080"
   ```

4. 安裝 IDE 工具
   
   - VS Code
     
     https://code.visualstudio.com/ 
   
   - 建議安裝套件
     
     ```textile
     Chinese (Traditional) Language Pack for Visual Studio Code 
     EditorConfig for VS Code
     ES7+React/Redux/React-Native snippets
     ESLint
     formate-custom: CSS/LESS/SCSS formatter
     JavaScript(ES6) code snippets
     Prettier - Code formatter
     简体与繁体互转
     ```

## 安裝 React 專案

1. 前往 `工具` 資料夾，解壓縮 `ant-design-pro`

2. 前往 `ant-design-pro` 根目錄，透過 CMD 執行下面指令
   
   - **下載依賴**：`yarn`
   
   - **啟動**：
     
     - (node < 16) `yarn start` 
     
     - (node >= 16) `yarn start:new`
       主要是啟動前要先執行
       `set NODE_OPTIONS=--openssl-legacy-provider`
       來調整 openssl 設定，才能順利啟動
