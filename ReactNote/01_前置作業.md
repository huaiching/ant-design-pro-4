# 前置作業

## 環境搭建

1. 安裝 Node.js (npm)
   
   https://nodejs.org/en/ 

2. 安裝 yarn 
   
   前往 node 安裝資料夾，透過 CMD 執行 `npm install --global yarn`

3. 安裝 IDE 工具
   
   - VS Code
     
     https://code.visualstudio.com/ 
   
   - 建議安裝套件
     
     ESlint
     JS JSX Snippets
     ES7 React/Redux/GraphQL/React-Native snippets
     ESLint
     Prettier - Code formatter
     Chinese (Traditional) Language Pack for Visual Studio Code
