# JS 介紹 - 空值判斷

JavaScript 的空值 有 `undefined` 和 `null` 兩種

- `null`: 空指標

- `undefined`: 未初始化

---

## 判斷是否為 undefined

```ts
const b = undefined
if (b === undefined) {
  console.log('b 是 undefined')
} else {
  console.log('b 不是 undefined')
}
```

---

## 判斷是否為 null

```ts
const a = null
if (a === null) {
  console.log('a 是 null')
} else {
  console.log('a 不是 null')
}
```

---

## 判斷是否為空值 (undefined 和 null 皆算空值)

- `==` 可同時判斷 `null` 和 `undefined`

```ts
const a = null
if (a == null) {
  console.log('a 是 null 或 undefined')
} else {
  console.log('a 不是 null 和 undefined')
}
```
